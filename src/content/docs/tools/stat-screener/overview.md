Скринер для статистического арбитража помогает пройти путь от большого списка инструментов до проверенной парной гипотезы.

## Рабочий процесс

1. **Скринер** отбирает пары по коинтеграции, типу связи, ликвидности, размеру текущего отклонения и потенциалу прибыли.
2. **Бэктестер** применяет правила входа и выхода к истории и показывает распределение результатов.
3. **Калькулятор** подбирает размеры ног под заданный капитал и оценивает ожидаемый денежный результат.
4. **Уведомления** сообщают, когда спред достиг уровня входа или выхода.

Начните с [настройки скринера](/tools/stat-screener/screener/), а после отбора пары переходите в [бэктестер](/tools/stat-screener/backtester/).

:::tip
Сильное отклонение само по себе не делает сделку хорошей. Сначала подтвердите связь инструментов и возможность исполнить обе ноги, затем оценивайте потенциальную прибыль.
:::
